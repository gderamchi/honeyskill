# Public distribution and evidence availability

This HoneySkill repository preserves the earlier published SkillGate Git history and adds the hackathon development code. Published SkillGate v0.5.0 remains available in the original [gderamchi/skillgate repository](https://github.com/gderamchi/skillgate). This is a separate HoneySkill development publication, not a rewritten release.

## What is included

Active CLI source, financial policy modules, the declared Progent static-checker port and required license notice, native inspection, the Cisco adapter, authored inert payment fixtures, tests, compiled CLI and sanitized measured evidence. Cisco and Anvil are separate local prerequisites for their relevant commands; optional tests identify missing external tools rather than inventing successful integrations.

## What is withheld

The 616 third-party corpus files and negative-control task manifests are not redistributed because their rights and sensitive-content review are incomplete. Certain historical diagnostic excerpts, screenshots and provider response identifiers are also withheld. Source/provenance notes and acquisition scripts explain how an authorized researcher can obtain and verify those inputs independently. The public clone cannot reproduce the 114-case corpus run without reacquiring those inputs. It can build, test, run the controlled payment demonstration and inspect its own supplied skills.

All 114 recorded case outcomes remain visible in the [derived public comparison](evidence/security-v1/repair-2026-10-11/index-public.html), including false positives, false negatives, regressions and incomplete analyses. Unknown labels remain separate. Full local evidence was preserved; no prior result was changed to improve a score.

Original aggregate/case artifacts are preserved byte for byte. Files named `*-public.*` are explicit derived navigation views which redirect unavailable qualitative material to an availability note. Historical checksum manifests inventory a larger original bundle, so they must not be interpreted as a completeness claim for this public subset. The publication manifest records the actual included files.

## No credentials or production authority

No secrets, workstation paths, raw provider response IDs, live user wallet or private account state are required. All demonstration signatures target an owned loopback chain. Public Fuji requests are read-only. No model call is used by `payment-demo`; separate live inspection requires an authorized key and credits.

## Historical metadata boundary

The preserved, already-public SkillGuard-Lite evidence includes provider response identifiers in twelve historical files. These identifiers are not credentials and require separate authorization to retrieve provider data. This publication does not rewrite that historical evidence or claim those old files contain no provider metadata. Newly exported HoneySkill/repair artifacts exclude raw provider identifiers.
