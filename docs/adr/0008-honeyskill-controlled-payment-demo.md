# ADR 0008 — HoneySkill branding and a controlled payment demonstration

Date: 2026-10-11. Status: accepted for the authorized hackathon development scope.

## Decision

Rename active presentation and CLI to HoneySkill while keeping the SkillGate binary alias, historical identifiers, release tags and frozen evidence. Add a distinct `payment-demo` command rather than changing the original `demo` or benchmark protocol.

Use authored proposals replayed against identical local snapshots to isolate deterministic financial authorization. Verify native transaction receipts and balances; explicitly bound the minimal approval witness. Record fork source identity and distinguish a genesis fallback. Store actual measurements, separate unsupported outcomes, retain inspection failures, and keep normal-AI comparison unmeasured until a prospective paired experiment runs.

## Consequences

The demonstration can reproducibly show containment without a model credential or model variability. It does not show a live agent being induced to issue those proposals or generalize to unseen skills. Neutral public fixture names improve readability; manifest provenance remains mandatory. Submission assets explain both the demonstrated boundary and missing production integrations.
