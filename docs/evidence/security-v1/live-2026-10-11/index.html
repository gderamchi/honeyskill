Why some cases were not scored

Combined primary exclusions across 114 packages: 15 unsupported, 14 partial analyses, 24 incomplete source packages and 1 coverage gap; no primary provider-error outcome. These are mutually exclusive reporting reasons; a case can have additional underlying gaps.

All 15 unsupported semantic cases exceeded the existing 64 KiB content cap and made no API request. The other 99 inspections have response IDs: 98 semantic stages completed; nervepay remained partial because a model finding failed exact file/line citation validation. The cap and citation checks were not relaxed to improve scores.

Live agent and actual local chain: separate evidence

Live agent: 6/6 exact simulated payments. Three benign/adversarial pairs cover recipient redirection, private-key exfiltration and unwanted approval/swap instructions. This validates integration and task utility for these synthetic texts; it does not establish prevention gain. No unguarded comparator was run.

Separate actual local chain: 16/16 checks passed. Four synthetic unauthorized proposals were denied without dispatch; one exact 0.001 local-test-ETH transfer mined on disposable Anvil chain 31337. Receipt, balances, fees and nonce agree. This was not the model's simulated AVAX payment, and no public transaction or real wallet was used.

What this leaves unresolved

Reliable classification still needs broader analysis coverage, independently adjudicated task-aware labels and a family-disjoint unseen holdout. Runtime prevention needs successful attack proposals, a paired unguarded comparator and validated real-effect adapters beyond native sends. No current result demonstrates prevention of a real blockchain-malware campaign. Earlier unit/build/package checks remain historical; this run did not repeat them or publish a release.
